### 4.1.3 方法配置

主方法 `e1_ours`：`baseline → learn_add → exam → learn → exam → learn_trial → test`，切段单元 `K = 5`；`learn`/`learn_trial` 为逐 trial 审阅（`trial_level`），读写范围不受限（`revise_scope: both`），允许写新技能。训练集上产出技能库，测试集上比较“带库（folder）对裸弱模型”。

### 4.1.4 指标与统计口径（预先登记）

- **avg@3（条件口径，主指标）**：每题先对有判分的 trial 求平均，再对至少有一个有判分 trial 的题求平均；
- **avg@3（保守口径）**：所有题进分母，没有判分 trial 的题记 0；
- **pass@3**：至少有一个成功 trial 的题占比；
- 区间：按**题**配对自助法，10000 次重采样，种子 0，95% 百分位区间；
- 胜负平（W/L/T）：按题的均值比较；
- **对照噪声 SD**：对照臂把每题 trial 随机分两半、两半均值相减，2000 次重采样的 SD；
- pass@3 的配对检验用 McNemar 精确检验。

判分结论为 invalid / 缺失 / 接受空洞的 trial **不记 0**，从所在题的平均里拿掉，并在表脚注写出数量。

### 4.1.5 对照来源（两种，逐表注明）

- **同 run 对照（fresh_bare）**：每个 run 在测试集上新跑一份裸弱模型，与带库臂同 run 配对。用于主表、实验二、实验三、实验四的 a0/a1。

## 4.3 RQ2：强弱模型之间的执行不一致

**问题**：强模型写的技能，弱模型能否用；技能收益是否取决于教师/学生的配对？进一步：**裸跑最强的模型是否就是最好的教师**？
**叙事**：我们预期裸跑的 D 强于裸跑的 X（qwen3.8-27b），但 X 教 Q 的效果好于 D 教 Q——即“教师的强弱”与“教师教得好不好”不是同一件事，模型异质性必须按配对来看。
**设置**：实验二各臂只跑 `baseline → learn_add → exam → test`：P02 从教师成功、学生失败的轨迹写出技能，直接接受（不演化、不整理）；教师同时是作者，学生同时是执行者。训练 39 / 测试 134 ×3，folder 交付，各自与同 run 的裸学生对照。

| 教师→学生 | 带库 avg@3 | 裸学生 avg@3 | 技能带来的差 [95% CI] | W/L/T | 噪声 SD | 库大小 |
|---|---|---|---|---|---|---|
| D→D | 0.990 | 0.980 | +0.010 [-0.005, +0.027] | 6/3/125 | 0.016 | 6 |
| D→Q | 0.893 | 0.872 | +0.021 [-0.017, +0.060] | 27/19/88 | 0.038 | 15 |
| Q→Q | 0.884 | 0.873 | +0.011 [-0.035, +0.056] | 31/27/76 | 0.037 | 10 |
| Q→D | 0.980 | 0.988 | **-0.007** [-0.025, +0.010] | 5/8/121 | 0.013 | 5 |

训练集裸跑（同一批题）：教师 D **111/117 = 94.9%**，学生 Q **96/117 = 82.1%**，差 12.8 个点；缺口集中在 cool、two-object、heat 三类。

**已验证的结论**：
1. 四个臂的技能收益都在 1–2 个点以内，全部跨 0 且小于噪声——不能声称任何一臂有效；
2. **Q→D 是唯一方向为负的臂**（弱模型写的技能给强模型用，5 题变好、8 题变差），说明技能转移是**不对称**的：强→弱还有一点帮助，弱→强没有收益甚至轻微添乱。这与“强模型技能弱模型用不明白”的强版本相反；
3. D 的裸通过率已 98–98.8%，D→D/Q→D 两臂存在明显天花板；真正有空间的只有学生是 Q 的两臂（~87%）。

### 补充臂：X = qwen3.8-27b（最高优先级，运行中）

为检验“裸跑最强 ≠ 最好的教师”，新增两个 run：

| run | 目的 | 配置 | 对照 | 状态 |
|---|---|---|---|---|
| `e1_bare_x` | 裸跑 X 在 ALFWorld 测试集上的通过率 | test-only，空库 `whole_bank`，executor = X；对照为零执行的冻结文件（仅占位，不产生数字） | 裸 X 的数字取 with_bank 臂（空库即裸跑） | **已完成**：条件口径 1.000，保守口径 0.985，pass@3 0.985；14 个题有 infra trial |
| `e2_x2q` | X 教 Q：X 写的技能给 Q 用 | 四相位，教师/作者 = X，学生/执行者 = Q，出题/裁判 = D | 同 run 裸 Q | **运行中**（baseline 教师臂 117 单元已派发） |

对照预期（写进本节，结果出来前定死）：

| 比较 | 指标 | 预期 | 实测 |
|---|---|---|---|
| 裸 D vs 裸 X | 测试集 avg@3 | D > X | **不成立**：裸 X 保守口径 0.985（条件 1.000），裸 D 为 0.980 / 0.988，三者都在天花板附近、差异在噪声内 |
| X→Q vs D→Q | 带库 avg@3，以及技能带来的差 | X→Q 更好；若成立，说明教师的教学质量不能由裸跑强度替代 | 待补（X→Q 终测进行中） |

**关于“裸跑 dpsk 更强”的前提**：ALFWorld 测试集上两个强模型都接近上限（98–100%），裸 X 甚至条件口径全对、保守口径与 D 的两个对照同量级；**这批数据不支持“裸 D 明显强于裸 X”**。X 的 14 个 infra trial 来自高并发下的端点连接失败，条件口径把它们剔除后得到 1.000，存在幸存者偏差；保守口径 0.985 更稳妥。因此 RQ2 的叙事若坚持“D 更强、但 X 教得更好”，前半句需要改成“两者裸跑接近上限、分不出强弱”，后半句等 X→Q 结果。

现有可填的部分：裸 D 的测试集对照为 **0.980（D→D）与 0.988（Q→D）**；D→Q 的带库 0.893、差 +0.021。

## 4.4 RQ3：子任务归因 vs 整条轨迹

**问题**：把执行轨迹切成子任务作为学习/归因单元，是否优于整条轨迹一个单元？
**设置**：`K=5`（主方法）对 `K=1`（三个学习相位都只切 1 段，整条轨迹一个单元）；其余配置完全相同，各自与同 run 裸 Q 对照。

| 臂 | avg@3 | Δ vs 自身对照 [95% CI] | W/L/T | 对照 avg@3 | 噪声 SD | Δ vs K=5 [95% CI] | W/L/T vs K=5 |
|---|---|---|---|---|---|---|---|
| K=5（本方法） | 0.915 | +0.024 [-0.017, +0.065] | 26/21/87 | 0.892 | 0.034 | — | — |
| K=1（整条轨迹） | 0.900 | +0.027 [-0.015, +0.070] | 26/20/88 | 0.873 | 0.036 | -0.015 [-0.055, +0.022] | 20/23/91 |

**已验证的结论**：K=5 比 K=1 高 1.5 个点（K=5 赢 23 题、输 20 题），但区间跨 0 且小于两臂噪声。**在这个规模下，“切成子任务做归因”没有显著优于“整条轨迹一个单元”**；论文不能写成子任务归因更好。
