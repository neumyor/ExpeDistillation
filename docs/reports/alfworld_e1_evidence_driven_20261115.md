## 五、口径说明与限制

1. **差值包含 playbook 与技能库两部分**：带库臂显示演化的 playbook 并交付技能文件夹，裸跑两者都没有。
   技能库在 playbook 之上的贡献要等 `no_skills` 消融臂（按计划推迟）；
2. **与历史结果的关系**：此前 ALFWorld 结果都是执行温度 0。其中 exp3_k5_final（0.6990）用
   llmcenter 学生；V7（0.8060）、手写 playbook（0.8035）、K=1/3/5（0.8010 / 0.8109 / 0.8085）、
   SkillOpt（0.7338）用 vLLM 学生，但对照都是 llmcenter 的冻结文件。本报告的 0.7736 是温度 0.95
   下的数字，与这些数字在协议上不同，**不能直接并列比较或排名**。若要比较，需要在温度 0.95 下
   重跑相应臂，或在温度 0 下重跑本方法；
3. **两物体任务退步**需要归因（是卡、playbook 还是学生在这一类上的方差），在归因之前不应把总分
   提升解释为各类型一致的改进；
4. 只有一次 run；单 run 噪声约 ±6pp（见噪声底），本次差值超过噪声底，但仍应至少复跑一次。
