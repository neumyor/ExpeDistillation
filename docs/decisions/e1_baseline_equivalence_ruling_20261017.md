## 背景

E1–E6 对归档语义基线的等价验收中，E1 的"最终技能库行多重集全等"对基线不成立。全部差异指向同一根因：修复方案 R6 把加技能路径的证据收窄为只读 D 相位强模型轨迹（W1-E 落地、W3-S 接线），旧世界弱臂失败段产出的"诊断技能"在相位世界没有生产者，技能库更小，一切由库派生的量（E2 终态、E3 检索审计、E4 调用与 prompt、E6 痕迹与注入块）随之不同。

## 裁决

**接受 R6 的收窄，认可披露报告为验收口径。** 理由：

1. 详细修复计划 R6 明确写了加技能证据是"D 相位强模型切段"（用户批准的计划内容），边界定稿 §2.5 把"从哪几段经验里学"留为找证据的不同做法之一，两者不矛盾；
2. 修复方案硬约束第 5 条"保持等价，或逐处披露差异"为这类设计性差异预留了披露通道；
3. 差异已机器枚举、逐字节钉死在 `tests/fixtures/golden_acceptance/wave4_e1_e6_disclosure.json`，standing test 对任何新增差异或已披露差异的回归都会转红——披露是可审计的，不是口头声明；
4. 恢复弱臂诊断技能产出属于新的方法行为开发，超出本次架构重构的范围；若后续研究需要，按"新增一块积木"的流程先改 README 再实现。
